# Manual de usuario pendiente

Cuando terminen las primeras fases operativas, preparar un manual de usuario para pruebas y futuros usuarios.

Temas a documentar:

- Productos, unidades, presentaciones, lotes y proveedores del producto.
- Compras: pedidos, recepciones parciales, compras directas e impacto en inventario.
- Inventario: movimientos, recibos, despachos, lotes y vencimientos.
- Ventas: cotizaciones, conversiones parciales y despachos.
- Reglas de anulacion, cierres parciales y trazabilidad entre documentos.

Objetivo: que una persona pueda probar el sistema paso a paso sin conocer la estructura interna.
